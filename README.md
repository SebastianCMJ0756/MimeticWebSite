 Mimetic — Gemelo Digital

Pagina oficial de Mimetic, un sistema para la gestión inteligente 
del flujo de pacientes en hospitales.

------------|-----------|----------|----------|---------|--------|--------|------------|
----- Tecnologías y lenguajes utilizados para la creación de la web:

  Lenguajes:
    HTML: Estructura principal de la web y capas semánticas.
    CSS: Estilos personalizados, distintos efectos y diseño adaptativo.
    JavaScript: Lógica del sistema, control de eventos y animaciones.

   Librerías y Herramientas
     [OGL]:Librería WebGL ligera para el renderizado del fondo animado en 3D.
     Tailwind CSS: Framework de utilidades CSS para maquetación rápida.
